# BLACKSITE-01 — Nordic Facility Tycoon

A browser-based tycoon game where you build and expand the fictional BLACKSITE-01 underground research facility.

## Current features

- Build facility rooms and expand the site
- Earn Research Points (RP) automatically
- Track Research Points per second
- Build:
  - Power Generators
  - Security Checkpoints
  - Research Labs
  - Containment Chambers
- Purchase Facility Upgrades to increase research generation
- Responsive layout for desktop and smaller screens
- Single-file HTML game — no installation required

## How to play

1. Open the game's web page.
2. Start with the available Research Points.
3. Select a room from the construction menu.
4. Spend RP to build it.
5. Your facility then generates RP automatically.
6. Keep expanding the Blacksite and improving its research output.

## Project

This is part of the BLACKSITE-01 / Nordic fictional universe.

The game is currently focused on the facility-construction side of the project. Future updates can expand the layout into connected corridors, sectors, security systems, research areas, containment systems, and more Nordic-related facility mechanics.
