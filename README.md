# BLACKSITE-01 — Nordic Facility Tycoon

A browser-based tycoon game where you build and expand the fictional BLACKSITE-01 underground research facility.

## Current features

- Build facility modules that physically appear in the facility
- Earn Research Points (RP) automatically
- Track Research Points per second
- Build:
  - Power Systems
  - Security Systems
  - Research Wings
  - Containment Wings
- Purchase Facility Expansion upgrades
- Expansion boosts existing and future module production
- Unlimited module construction
- Built-unit counters for each module
- Online status and unit identification for constructed systems
- Responsive layout for desktop, tablet, and mobile screens
- Single-file HTML game — no installation required

## How to play

1. Open the game's web page.
2. Start with the available Research Points.
3. Choose a facility module from the construction menu.
4. Spend RP to build it.
5. The module is added visibly to BLACKSITE-01.
6. Built modules generate RP automatically.
7. Purchase Facility Expansion upgrades to increase production.
8. Keep expanding the facility and increasing its research output.

## Project

This is part of the BLACKSITE-01 / Nordic fictional universe.

The game focuses on constructing a growing underground research facility. Each purchase changes the visible facility rather than filling separate empty plots.

Future updates can expand the facility into connected corridors, sectors, security systems, research areas, containment systems, and more Nordic-related mechanics.
